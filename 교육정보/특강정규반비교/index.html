01수업 이름보다 목표와 범위를 묻기

특강은 특정 기간이나 주제를 중심으로 구성되는 경우가 있지만 실제 운영은 학원과 과정마다 다릅니다. 정규 수업도 반드시 느리거나 기초 중심이라는 뜻은 아닙니다. 이번 수업의 시작 수준과 끝날 때 다룰 내용을 확인하세요.

지난 과제의 막힌 부분이 그 범위에 포함되는지 물어봅니다. “겨울방학 집중”이라는 소개만으로 필요한 기초를 다루거나 모든 영역을 완성한다고 판단하지 않습니다.

02기간과 수업 사이 연습 시간 비교하기

수업 날짜와 이동 시간을 달력에 넣고 설명을 다시 확인하거나 직접 연습할 시간을 계산합니다. 짧은 기간에 수업이 몰리면 이전 내용을 이해하기 전에 다음 수업이 진행될 수 있으므로 보완 방법을 묻습니다.

현재 정규 수업을 계속 들으면서 특강을 더한다면 두 수업의 과제가 겹치는지 확인합니다. 같은 단원을 다른 자료로 반복하는 것이 필요한지, 과제량만 늘리는지도 학생의 수행으로 판단하세요.

03질문·피드백·종료 뒤 연결 확인하기

모르는 부분을 언제 질문할 수 있는지, 결석이나 이해 부족 때 어떤 자료와 확인을 받을 수 있는지 묻습니다. 종료 뒤 복습할 자료와 다음 학기 연결 과제가 있는지도 확인하세요. 단기간이라는 이유만으로 질문 기회가 충분하다고 가정하지 않습니다.

교습비와 포함된 자료, 추가 비용, 일정 등 실제 조건은 해당 지점의 안내로 확인합니다. 이 비교는 채움학습의 모든 지점이 특강과 정규반을 모두 운영한다는 뜻이 아닙니다.

04한 가지 확인 과제로 선택 검토하기

목표 단원에서 학생이 자료 없이 설명하거나 새 문제를 시작할 수 있는지 확인할 과제를 정합니다. 수업을 많이 듣는 것과 혼자 사용하는 것은 구분해서 봅니다.

기간이 끝났을 때 해결한 질문과 남은 내용을 나누고 다음 공부에 연결합니다. 수업 속도가 맞지 않으면 분량·지원·과정 선택을 상의할 수 있도록 시작 전 확인 기준을 남겨두세요.
