먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 노트 정리에 시간이 대부분 든다.
  • 정의는 있지만 조건이나 이유가 없다.
  • 필기를 덮으면 배운 내용을 말하기 어렵다.

왜 이렇게 살펴볼까요?

정리가 보기 좋아도 내용을 스스로 설명하지 못할 수 있습니다. 복습용 질문과 직접 답한 결과를 연결하세요.

필기의 오류나 빠진 조건은 교과서와 수업 자료로 확인해야 합니다. 기억으로 채우고 끝내지 않습니다.

실행 순서 4단계

  1. 자료의 위치 연결하기

    교과서 쪽과 수업 필기의 단원을 연결해 근거를 다시 찾을 수 있게 합니다.

  2. 핵심 관계 남기기

    개념·조건·비교·이유 중 현재 단원에 필요한 내용만 짧게 정리합니다.

  3. 질문 칸 만들기

    정리한 내용을 설명할 질문과 수업 중 이해하지 못한 부분을 적습니다.

  4. 덮고 답한 뒤 수정하기

    질문에 직접 답하고 원문과 비교해 빠진 조건이나 잘못된 연결을 고칩니다.

PRACTICE EXAMPLE

방법을 이해하는 연습 예시

연습 예시: ‘속력=거리/시간’만 적는 대신 ‘각 양의 단위는 무엇인가, 평균 속력은 어떤 뜻인가’를 질문으로 남깁니다. 이후 자료를 덮고 답한 뒤 원문과 비교해 설명을 수정합니다.

방법을 보여 주기 위해 만든 예시입니다. 실제 학생의 사례나 성적 결과가 아닙니다.
