먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 상담 질문이 ‘성적이 오를까요’뿐이다.
  • 학생이 어떤 도움을 받는지 자료가 없다.
  • 희망 일정과 실제 가능한 시간이 다르다.

왜 이렇게 살펴볼까요?

점수나 진도표만으로는 조건 읽기, 개념 선택, 과제 관리 중 무엇이 필요한지 알기 어렵습니다. 실제 과제의 과정을 함께 보세요.

상담의 설명과 실제 수강 조건은 별도로 확인해야 합니다. 비용·학년·일정·자리 여부는 해당 지점의 안내를 따릅니다.

실행 순서 4단계

  1. 대표 과제 두 가지 고르기

    혼자 해결한 것과 도움받은 것을 골라 사용한 힌트와 막힌 지점을 표시합니다.

  2. 일정과 목표 정리하기

    학교 일정, 이동 시간, 현재 과제와 단기적으로 확인할 행동을 적습니다.

  3. 지원 방식 질문하기

    어떻게 기초를 확인하고 질문·독립 풀이·후속 확인을 지원하는지 구체적으로 묻습니다.

  4. 수강 조건 따로 확인하기

    과목별 학년, 비용 구성, 일정과 변경 조건을 지점 안내로 확인하고 미확인 사항을 남깁니다.
