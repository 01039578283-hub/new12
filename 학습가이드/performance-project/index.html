먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 마감은 알지만 평가 기준을 모른다.
  • 자료를 붙였지만 자기 설명이 없다.
  • 모둠의 역할과 제출 담당이 불분명하다.

왜 이렇게 살펴볼까요?

자료를 모으는 데 시간을 다 쓰면 설명과 수정 과정이 남지 않습니다. 제출물의 형식, 내용, 출처와 마감 조건을 먼저 나누세요.

수업 중 수행, 개인·모둠 활동, 외부 도움과 도구 사용 허용 범위는 과제별로 다릅니다. 학교 안내 밖의 허용 여부는 확인이 필요합니다.

실행 순서 4단계

  1. 조건을 표로 옮기기

    안내문에서 주제·분량·형식·마감·출처·도구 사용 조건을 적고 애매한 항목은 질문합니다.

  2. 기준별 근거 배치하기

    각 평가 항목을 설명할 문장이나 자료를 대응시키고 없는 근거를 찾습니다.

  3. 초안과 수정 시간 나누기

    자료 수집 후 초안을 만들고 기준표와 대조해 빠진 설명과 출처를 고칩니다.

  4. 제출 확인하기

    파일 이름·열림 여부·제출 경로를 확인하고 제출 완료 화면이나 안내에 맞는 확인 방법을 기록합니다.
