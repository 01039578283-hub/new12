먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 단어 시험은 맞지만 지문 뜻이 이상하다.
  • 철자·발음을 함께 확인하지 않는다.
  • 아는 단어와 다시 볼 단어를 섞어 반복한다.

왜 이렇게 살펴볼까요?

한 단어가 문맥에 따라 다른 의미나 품사로 쓰일 수 있습니다. 뜻 목록만 외우기보다 현재 지문에서 어떤 역할을 하는지 확인하세요.

읽을 때 알아보는 것과 직접 떠올려 쓰는 것도 다릅니다. 두 결과를 구분하면 복습 대상을 고르기 쉽습니다.

실행 순서 4단계

  1. 배운 글에서 고르기

    현재 읽는 글에서 중요한 단어를 소수 고르고 해당 문장을 함께 적습니다.

  2. 문맥과 형태 확인하기

    사전이나 수업 자료로 이 문장의 의미·품사·발음·함께 쓰는 표현을 확인합니다.

  3. 뜻과 문장을 떠올리기

    자료를 덮고 의미를 말하거나 문장의 빈칸을 채워, 알아본 단어와 직접 쓴 단어를 구분합니다.

  4. 다른 문장에 연결하기

    짧은 새 문장에서 사용하고 다음 복습에서 잊거나 잘못 쓴 부분을 우선 확인합니다.

PRACTICE EXAMPLE

방법을 이해하는 연습 예시

연습 예시: ‘a light bag’의 light는 ‘가벼운’입니다. ‘turn on the light’와 비교해 문맥을 구분하고, ‘a light box’처럼 같은 쓰임의 새 문장을 만듭니다. 여러 뜻을 한꺼번에 모두 외울 필요는 없습니다.

방법을 보여 주기 위해 만든 예시입니다. 실제 학생의 사례나 성적 결과가 아닙니다.
