왜 이렇게 살펴볼까요?

본문 순서가 기억나도 단어의 형태나 표현이 달라지면 의미를 놓칠 수 있습니다. 실제 이해와 기억을 구분해 볼 필요가 있습니다.

학교마다 범위와 평가 방식이 다르므로 특정 문항 유형이 반드시 나온다고 단정하지 않습니다.

실행 순서 4단계

  1. 범위와 수업 자료 모으기

    학교 안내의 단원·본문·추가 자료를 확인하고 자료 누락을 표시합니다.

  2. 핵심 기능 나누기

    어휘 쓰임, 문장 구조, 글의 관계, 과제의 쓰기 조건으로 점검 항목을 만듭니다.

  3. 자료 없이 적용하기

    핵심 문장을 설명하거나 배운 표현으로 짧게 쓰고 단순 암기로 맞힌 부분과 나눕니다.

  4. 틀린 기능을 보완하기

    학교 피드백과 수업 자료로 오류를 확인한 뒤 해당 기능을 다른 문장에 적용합니다.
