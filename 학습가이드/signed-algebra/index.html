왜 이렇게 살펴볼까요?

음수를 빼는 것과 음수를 곱하는 것은 같은 행동이 아닙니다. 부호 규칙을 한 문장으로 묶기보다 실제 식의 연산을 읽어야 합니다.

풀이를 생략하면 처음 달라진 줄을 찾기 어렵습니다. 익숙해질 때까지 변형의 근거를 간단히 남기세요.

실행 순서 4단계

  1. 연산부터 읽기

    음수의 기호와 빼기 기호를 구분하고 괄호가 묶는 범위를 표시합니다.

  2. 한 변형씩 쓰기

    분배법칙이나 동류항 정리 중 한 가지 변형만 한 줄에 쓰고 근거를 옆에 적습니다.

  3. 처음 다른 줄 비교하기

    정확한 풀이와 비교해 마지막 답이 아닌 최초의 잘못된 변형을 찾습니다.

  4. 값을 넣어 검토하기

    문자에 간단한 값을 넣어 변형 전후 값이 같은지 확인하고 틀린 항을 고칩니다.

PRACTICE EXAMPLE

방법을 이해하는 연습 예시

연습 예시: -2(x-3)은 -2x+6입니다. -2x-6으로 썼다면 x=0을 넣어 원래 식은 6, 바꾼 식은 -6임을 확인합니다. 하나의 값에서 맞았다고 모든 변형이 증명된 것은 아닙니다.
