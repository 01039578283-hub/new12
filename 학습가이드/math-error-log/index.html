먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 모든 원인이 ‘실수’ 또는 ‘모름’이다.
  • 노트는 길지만 다시 풀지 않는다.
  • 맞는 답을 외워 같은 문제만 맞힌다.

왜 이렇게 살펴볼까요?

오답의 답과 해설을 옮겨 쓰는 것만으로는 자신의 판단이 어떻게 바뀌었는지 알기 어렵습니다. 처음 달라진 줄과 고친 근거를 중심으로 기록하세요.

기록을 남긴 뒤 실제로 다시 풀어야 다음 행동이 맞았는지 확인할 수 있습니다. 노트의 분량과 학습 결과를 구분합니다.

실행 순서 4단계

  1. 최초 오류 찾기

    조건 표시와 풀이를 비교해 처음 잘못 읽거나 바꾼 지점을 표시합니다.

  2. 원인과 행동 연결하기

    개념 부족은 재설명, 조건 누락은 관계 표시, 계산 오류는 해당 변형과 검산 연습을 고릅니다.

  3. 짧은 기록 남기기

    문제 위치·최초 오류·고친 근거·다음 행동만 쓰고 해설 전체 복사는 줄입니다.

  4. 자료 없이 다시 확인하기

    이후 학습에서 다시 풀고, 같은 기능을 쓰는 새 문제에서 적용 여부를 확인합니다.

방법을 이해하는 연습 예시

연습 예시: -3(a-2)를 -3a-6으로 쓴 경우 ‘분배할 때 두 번째 항의 부호를 놓침’과 ‘-3×(-2)=6을 설명한 뒤 새 식으로 확인’을 적습니다. 마지막 답만 지우고 고치지 않습니다.

방법을 보여 주기 위해 만든 예시입니다. 실제 학생의 사례나 성적 결과가 아닙니다.
