해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 알파벳 이름만 말하며 단어를 못 읽는다.
  • 그림이 없어지면 같은 단어를 놓친다.
  • 읽은 단어의 뜻을 설명하지 못한다.

왜 이렇게 살펴볼까요?

그림을 보고 단어를 맞히는 것과 글자를 보고 읽는 것은 다릅니다. 그림 없이도 소리를 이어 읽는지 살펴보세요.

소리를 정확히 읽어도 뜻을 모를 수 있습니다. 초기 읽기에서는 단어 읽기와 의미 확인을 같이 연결합니다.

실행 순서 4단계

  1. 배운 소리 확인하기

    교재와 수업에서 배운 글자·소리 대응을 확인하고 아직 안 배운 유형은 구분합니다.

  2. 소리를 이어 읽기

    배운 대응을 쓰는 짧은 단어를 소리로 나누어 확인한 뒤 이어 읽습니다.

  3. 단어와 뜻 연결하기

    읽은 단어의 의미를 그림·행동·짧은 설명으로 확인합니다.

  4. 짧은 문장으로 적용하기

    이미 배운 단어가 포함된 문장을 읽고 누가 무엇을 하는지 말해 봅니다.
