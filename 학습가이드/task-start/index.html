왜 이렇게 살펴볼까요?

준비물이 없거나 처음부터 어려운 과제이면 시작 자체가 막힐 수 있습니다. 미루는 행동을 하나의 성격으로 해석하지 마세요.

작게 시작해도 개념이 계속 어렵다면 과제 크기만 줄일 것이 아니라 필요한 설명을 받아야 합니다.

실행 순서 4단계

  1. 시작 직전 상황 보기

    시간·자리·자료·첫 문제의 난도를 확인하고 무엇이 부족한지 적습니다.

  2. 첫 행동 하나 정하기

    자료 한 장 펼치기, 문제의 조건 표시하기처럼 바로 수행할 행동을 고릅니다.

  3. 끝나는 작은 과제 만들기

    질문 하나 설명하기나 예제의 첫 관계 찾기처럼 완료를 확인할 크기로 나눕니다.

  4. 막힘에 맞춰 다음 결정하기

    작게 해도 막히면 개념 도움을, 할 수 있으면 다음 과제를 정하고 실제 시간을 기록합니다.
