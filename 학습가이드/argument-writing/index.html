먼저, 이런 상태인지 확인하세요

해당하는 항목을 현재 과제와 비교해 보세요. 모든 항목이 같은 원인에서 생기는 것은 아닙니다.

  • 주장은 있지만 이유가 모두 느낌이다.
  • 자료를 복사했으나 연결 설명이 없다.
  • ‘모두’·‘항상’ 같은 표현의 근거가 없다.

왜 이렇게 살펴볼까요?

자료의 내용과 자신의 판단을 섞으면 출처가 무엇을 말했는지 불분명해집니다. 자료의 사실과 그 사실에서 내리는 해석을 나누세요.

쓰기 전 계획과 쓰고 난 후 수정은 서로 다릅니다. 초안을 읽으며 근거 없는 주장과 단정한 범위를 확인합니다.

실행 순서 4단계

  1. 주장을 좁혀 쓰기

    독자·목적·과제 조건을 확인하고 주장할 범위를 한 문장으로 적습니다.

  2. 근거와 출처 확인하기

    자료의 작성자·발행 시점·실제 내용을 확인하고 주장을 뒷받침하는 부분을 고릅니다.

  3. 연결 이유 설명하기

    각 자료가 왜 주장의 근거인지 쓰고 자료가 말하지 않은 내용을 덧붙이지 않습니다.

  4. 반대 질문으로 수정하기

    다른 조건이나 반론을 생각하고 과장된 범위, 빠진 이유와 문단 순서를 고칩니다.

PRACTICE EXAMPLE

방법을 이해하는 연습 예시

연습 예시: ‘교실에서 읽을 책을 학생이 함께 고르자’라는 주장은 참여 방법과 선택 기준을 설명해야 합니다. 자료가 단지 학생의 선호를 보여 준다면 그것만으로 성적이 오른다는 주장까지 넓히지 않습니다.

방법을 보여 주기 위해 만든 예시입니다. 실제 학생의 사례나 성적 결과가 아닙니다.

다음에 확인할 것

주장마다 근거와 연결 이유가 있는지, 반대 조건을 반영했는지 확인합니다. 근거가 부족하면 자료를 추가하거나 주장의 범위를 좁힙니다.

잘 안 될 때는 이렇게 조정하세요

출처를 적는 것과 타인의 글을 자기 글로 제출하는 것은 다릅니다. 학교의 인용·도구 사용 조건을 확인하고 자신의 설명을 씁니다.

학부모는 이렇게 도울 수 있습니다

학생이 자료와 자신의 의견을 나누어 설명하게 해 보세요. 부모의 주장을 대신 넣지 않고 독자가 궁금해할 질문을 제공합니다.

처음부터 완벽하게 써야 하나요?

초안에서 생각을 드러낸 뒤 조건과 근거를 확인하며 수정할 수 있습니다.
